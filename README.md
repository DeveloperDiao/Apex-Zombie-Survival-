# Zombie Survival

Mobile-first top-down 2D survival prototype using Phaser 3, TypeScript, and Vite.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Prototype gameplay

Drag anywhere on the game screen to move your survivor. Auto-fire targets the nearest zombie. Survive 60 seconds to finish Level 1. Coins are **local prototype values only** and are not saved or verified by a server. No login or admin features are implemented yet.

## Next phases

Build a secure Express backend, PostgreSQL player database, admin-only account creation, admin coin grants, server-verified economy, upgrade shop, and additional levels. Never commit secrets or plaintext passwords.
